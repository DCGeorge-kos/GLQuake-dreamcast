Get the latest BootDreams from NaiSan89 :

https://github.com/NaiSan89/BootDreams/releases/tag/1.0

Launch it and make sure that DiscJuggler is selected.
Under Extras ISO settings choose Full filenames, Joliet and Rock Ridge.
Select size for a dummy file if you decide to burn this disc image on a CD-R.
Browse to the folder of your project that should hold :

*A folder called ID1 containing PAK0.PAK (you can also add config files and PAK1.PAK to play the entire game)

*1ST_READ.BIN

*IP.BIN (if missing, BootDreams will ask you to create one ; select yes once prompted)

If you wanna give a name to your ISO click under CD label and type whatever you want.
Click on process then OK to confirm.
